# Nexus V0.2.0 Release Notes / Notas de versión

## Español
Primera publicación estructurada de Nexus v0.2.0 basada en el motor v0.1. Incluye prefijo `.nexus`, alias `info` e `ids`, formato de estado verde y documentación bilingüe. No reescribe la arquitectura. La obligatoriedad de IDs numéricos y la validación en el juego real quedan pendientes.

## English
Initial structured Nexus v0.2.0 release based on the v0.1 engine. Adds the `.nexus` prefix, `info` and `ids` aliases, green status formatting, and bilingual documentation. Numeric-only IDs and in-game validation remain future work.

## Testing / Pruebas
No se ha probado en una instalación real de Minecraft PE 1.0.9 + Toolbox 3.2.29. Haz copia de seguridad y verifica en el juego antes de depender de esta versión.
