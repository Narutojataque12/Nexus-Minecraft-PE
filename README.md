# Nexus — Minecraft PE

**Español:** Motor experimental de mods para Minecraft Pocket Edition 1.0.9 con Toolbox 3.2.29, escrito en JavaScript ES5 para Rhino/ModPE. No es Forge oficial ni es compatible automáticamente con versiones modernas de Minecraft.

**English:** Experimental mod engine for Minecraft Pocket Edition 1.0.9 with Toolbox 3.2.29, written in ES5 JavaScript for Rhino/ModPE. It is not official Forge and does not automatically support modern versions of Minecraft.

## Inicio rápido / Quick start

1. Descarga una versión desde [Lanzamientos / Releases](https://github.com/Narutojataque12/Nexus-Minecraft-PE/releases).
2. Haz una copia de seguridad / Back up your game and scripts.
3. Carga el archivo del motor descargado como script principal en Toolbox / Load the downloaded engine as the main Toolbox script.
4. Coloca los mods compatibles en `/sdcard/Nexus/Mods/`.
5. Usa los comandos del juego: `/Nexus help`, `/Nexus info` y `/Nexus ids`.
6. Prueba un mod a la vez / Test one mod at a time.

Consulta la [guía bilingüe para crear mods](docs/INSTRUCCIONES_CREAR_MODS.md) / See the [bilingual mod guide](docs/INSTRUCCIONES_CREAR_MODS.md).
