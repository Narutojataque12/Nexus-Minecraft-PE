# Nexus — Minecraft PE

**Español:** Motor experimental de mods para Minecraft Pocket Edition 1.0.9 con Toolbox 3.2.29, escrito en JavaScript ES5 para Rhino/ModPE. No es Forge oficial ni es compatible automáticamente con versiones modernas de Minecraft.

**English:** Experimental mod engine for Minecraft Pocket Edition 1.0.9 with Toolbox 3.2.29, written in ES5 JavaScript for Rhino/ModPE. It is not official Forge and does not automatically support modern Minecraft versions.

## Versión / Version
- Engine: **0.2.1**
- Motor principal / Main engine: [engine/Nexus_V0.2.1.js](engine/Nexus_V0.2.1.js)
- Versión anterior / Previous version: [Old Versions/Nexus_V0.1.js](Old%20Versions/Nexus_V0.1.js)

## Inicio rápido / Quick start
1. Haz una copia de seguridad / Back up your game and scripts.
2. Carga el motor V0.2.1 como script principal en Toolbox / Load V0.2.1 as the main Toolbox script.
3. Coloca los mods compatibles en `/sdcard/Nexus/Mods/` / Put compatible mods there.
4. Prueba `.nexus help`, `.nexus info` y `.nexus ids`.
5. Prueba un mod a la vez / Test one mod at a time.

Consulta la [guía bilingüe para crear mods](docs/INSTRUCCIONES_CREAR_MODS.md) / See the [bilingual mod guide](docs/INSTRUCCIONES_CREAR_MODS.md).
